# 公网部署方案（免费云 + Docker + 域名/HTTPS）

> 适用项目：悦己美妆智能客服 Agent（FastAPI :8000 + Streamlit :8501 + SQLite + Ollama bge-m3 嵌入）
> 目标：把本地项目变成**面试官可点击访问**的公网演示链接（HTTPS）
> 三个方案按"推荐度"排序，任选其一即可；方案 A 最省事，方案 B 零云成本，方案 C 长期挂机。

---

## 0. 部署前的统一准备（三个方案都要做）

### 0.1 依赖清单（部署环境需要什么）

| 依赖 | 用途 | 来源 |
|------|------|------|
| DeepSeek API Key | LLM 调用 | 已有（.env） |
| **Ollama + bge-m3 模型** | 向量嵌入（本项目 Embedding 走本地 Ollama） | 部署环境安装，见各方案 |
| data/ 目录 | 知识库索引 + SQLite 订单库/会话 | 随项目复制，或部署后跑一次 `gen_*`/`ingest` |
| .env | 密钥配置 | 复制本地 .env（含 DEEPSEEK_API_KEY） |

> ⚠️ **部署环境必须能跑 Ollama**（或改用 API 嵌入）。本项目 `embed()` 目前只实现 Ollama 通道，
> 部署时二选一：① 在服务器装 Ollama 并 `ollama pull bge-m3`（推荐）；② 以后补一个 DashScope API 嵌入通道（规划文档 §5.2 预留）。

### 0.2 本地自检（确保部署的是"能跑"的版本）

```bash
python -m scripts.check_env        # 全部 ✅
python -m pytest tests/ -q         # 50 项全过
```

## 方案 A：Hugging Face Spaces（Docker）—— 最推荐 ⭐

**为什么选它**：免费额度给到 **2 vCPU / 16GB RAM / 50GB 磁盘**，够装 Ollama + 跑双服务；
Docker Space 支持自定义 Dockerfile；**自带 HTTPS**（`https://xxx.hf.space`），无需买域名。
代价：Space **闲置 48 小时后休眠**（再次访问冷启动约 30-60 秒）；国内访问速度一般但可用。

### A.1 在项目根目录创建 `Dockerfile.space`

```dockerfile
# HF Spaces 专用：单容器跑 FastAPI(:8000 内部) + Streamlit(:7860 对外) + Ollama
FROM ubuntu:22.04

ENV DEBIAN_FRONTEND=noninteractive \
    PYTHONUNBUFFERED=1 \
    PIP_NO_CACHE_DIR=1

RUN apt-get update && apt-get install -y --no-install-recommends \
    python3 python3-pip python3-venv curl ca-certificates && \
    rm -rf /var/lib/apt/lists/*

# Ollama（嵌入模型运行时）
RUN curl -fsSL https://ollama.com/install.sh | sh

WORKDIR /app
COPY requirements.txt .
RUN python3 -m venv /opt/venv && \
    /opt/venv/bin/pip install -r requirements.txt

COPY . .
ENV PATH="/opt/venv/bin:$PATH"

# 数据卷（会话/订单库/追踪持久化）
VOLUME ["/app/data"]

COPY entrypoint.space.sh /entrypoint.space.sh
RUN chmod +x /entrypoint.space.sh

EXPOSE 7860
CMD ["/entrypoint.space.sh"]
```

### A.2 创建 `entrypoint.space.sh`（一键拉起 Ollama + API + 前端）

```bash
#!/bin/bash
set -e

echo "== 启动 Ollama =="
ollama serve &
OLLAMA_PID=$!
# 等 Ollama 就绪后拉取嵌入模型（首次较慢，之后有缓存）
for i in $(seq 1 30); do
  curl -s http://127.0.0.1:11434/api/tags >/dev/null 2>&1 && break
  sleep 1
done
ollama pull bge-m3

echo "== 初始化数据（缺则生成）=="
cd /app
[ -f data/raw/products.json ] || python -m scripts.gen_data
[ -f data/db/yueji.db ] || python -m scripts.gen_orders
[ -f data/processed/chunks.json ] || python -m scripts.ingest

echo "== 启动 FastAPI（内部 :8000）=="
python -m uvicorn src.api.main:app --host 0.0.0.0 --port 8000 &
API_PID=$!

echo "== 启动 Streamlit（对外 :7860）=="
# 前端 app.py 里 API 常量是 http://127.0.0.1:8000 —— 同容器内直连，无需改
streamlit run frontend/app.py --server.address 0.0.0.0 --server.port 7860 \
  --server.headless true --browser.gatherUsageStats false &
WEB_PID=$!

trap "kill $OLLAMA_PID $API_PID $WEB_PID" EXIT
wait
```

### A.3 上传并部署（Git 方式）

```bash
# 1) 在 huggingface.co 新建 Space：SDK 选 Docker，公开/私有均可
git remote add space https://huggingface.co/spaces/<你的用户名>/yueji-cs
git add Dockerfile.space entrypoint.space.sh
git commit -m "add space deployment"
git push space HEAD:main
```

### A.4 验证与运维

| 操作 | 命令/位置 |
|------|----------|
| 部署日志 | Space 页面 → Logs 标签 |
| 访问地址 | `https://<用户名>-yueji-cs.hf.space`（**自动 HTTPS**） |
| 防休眠 | 加一个免费定时器（如 GitHub Actions cron 每小时 GET 一次主页） |
| 停止 | Space 页面 → Settings → Pause |

> 数据持久化说明：Space 容器文件系统在**休眠/重启间一般保留**（SQLite 与会话在），但 HF 不保证；
> 正式使用建议把 `data/db` 定期备份，或后续迁移到托管数据库。

## 方案 B：Cloudflare Tunnel（零云成本，从你本机发布）—— 最快演示

**为什么选它**：不买服务器，用你**现有环境**（Windows 上已装 Ollama + 项目）；
一条隧道命令把本机 8000/8501 暴露公网，**自动 HTTPS**（`xxx.trycloudflare.com` 随机域名，或绑定自己的域名）。
代价：**本机必须保持开机**；免费随机域名每次重启会变（绑定域名则不变）。

### B.1 本机启动服务（如未启动）

```bash
# 项目目录（Windows：D:\traework\study\AI_Agent\悦己美妆智能客服Agent）
.venv\Scripts\activate
python -m uvicorn src.api.main:app --port 8000          # 终端1
streamlit run frontend/app.py --server.port 8501        # 终端2
```

### B.2 安装并创建隧道

```bash
# Windows：winget install Cloudflare.cloudflared
cloudflared tunnel --url http://localhost:8501
```

终端会打印一个 `https://xxxx.trycloudflare.com` 地址 —— **直接发给面试官即可**（HTTPS 免费自带）。

> 说明：默认只暴露前端 8501 即可（前端在服务器端调 127.0.0.1:8000，浏览器只访问 8501）；
> 如需暴露 API 文档：再开一个终端跑 `cloudflared tunnel --url http://localhost:8000`。

### B.3 绑定自己的域名（可选，地址永久稳定）

1. 注册免费域名：DuckDNS（`你的名字.duckdns.org`，免费，需每 5 分钟刷新 IP 或装客户端）；
2. 将域名指向隧道（named tunnel）：
   ```bash
   cloudflared tunnel create yueji
   cloudflared tunnel route dns yueji yourname.duckdns.org
   cloudflared tunnel run yueji
   ```
   即可通过 `https://yourname.duckdns.org` 访问（Cloudflare 免费提供 HTTPS）。

## 方案 C：Oracle Cloud Always Free（长期挂机）—— 需要信用卡，配置较繁

**为什么选它**：真正"永久免费"的云 VM（ARM 4 OCPU / 24GB 内存），适合长期在线。
**注意**：① 注册需信用卡验证，且 2025 年起 Oracle 对 Always Free 新注册政策有调整（可能不再对纯免费用户开放，需以官网为准）；② 国内直连不稳定，常需梯子；③ 首次开通要抢 ARM 实例，有失败率。

### C.1 开通 VM（简要步骤）

1. 注册 Oracle Cloud → 创建 **Always Free** ARM 实例（Ubuntu 22.04）；
2. 安全组放行 80/443（Web）与 22（SSH）。

### C.2 服务器上部署（Ubuntu）

```bash
# 1) 基础环境
sudo apt update && sudo apt install -y docker.io docker-compose-v2 python3-pip
sudo usermod -aG docker $USER && newgrp docker

# 2) 安装 Ollama（嵌入）
curl -fsSL https://ollama.com/install.sh | sh
ollama pull bge-m3

# 3) 拉取项目
git clone <你的仓库地址> yueji && cd yueji
cp .env .env  # 确保含 DEEPSEEK_API_KEY

# 4) 初始化数据
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m scripts.gen_data && python -m scripts.gen_orders && python -m scripts.ingest

# 5) 启动（用项目自带 compose：api:8000 + web:8501）
docker compose up -d --build
```

### C.3 域名 + HTTPS（免费）

```bash
# DuckDNS 免费域名 + Cloudflare 免费 CDN/HTTPS
# 1) 注册 https://www.duckdns.org 得到 yourname.duckdns.org
# 2) 注册 https://dash.cloudflare.com（免费计划），添加该域名做 DNS
# 3) Cloudflare → SSL/TLS → 开启 Full；创建 Origin 证书并在服务器 Nginx 里配置
# 4) 服务器装 Nginx 反向代理：
#    server_name yourname.duckdns.org;
#    location / { proxy_pass http://127.0.0.1:8501; proxy_http_version 1.1;
#                 proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; }
```

## 1. 通用部署注意点（三方案通用）

| 注意点 | 说明 |
|--------|------|
| **Ollama 内存** | bge-m3 约 1.2GB，加 API/Streamlit 后建议实例 ≥2GB 内存（方案 A/C 满足） |
| **CORS** | 前端浏览器只连 Streamlit（服务端转发 API），无需额外 CORS；API 已 `allow_origins=["*"]` |
| **WebSocket/SSE** | 前端用 SSE（`/api/chat/stream`）走服务端到服务端，不受浏览器跨域限制 |
| **密钥安全** | `.env` 不提交 git；公网部署后**立即在 DeepSeek 平台开启用量告警**，防止密钥被盗刷 |
| **限流** | API 已内置每会话 20 次/分钟；如需全局限流可在反向代理层加（Nginx `limit_req`） |
| **数据初始化** | 部署后首次访问前，务必确认 `check_env` 全绿、`ingest` 已跑（知识库索引是静态文件，需随项目复制或现场生成） |

## 2. 验收清单（部署完成自测）

```text
✅ https://<你的地址>/health        → {"status":"ok"}
✅ 浏览器打开首页 → 能发起对话
✅ 问"玻尿酸保湿面霜多少钱" → 正常回答 + 来源链接可点
✅ 问"我是油皮推荐什么" → 推荐卡片渲染
✅ 问"你们是骗子！" → 自动转人工
✅ 断网重启后再次访问 → 会话数据仍在（SQLite 持久化）
```

## 3. 三个方案怎么选（决策表）

| 你的情况 | 选 |
|---------|-----|
| 想最省事、接受休眠冷启动、要 HTTPS | **A：Hugging Face Spaces** ⭐ |
| 只想"面试时演示 1-2 小时"、不买任何东西 | **B：Cloudflare Tunnel**（本机开隧道） |
| 想长期 7×24 在线、愿意折腾注册 | **C：Oracle Cloud** |
| 已有云账号（阿里云/腾讯云） | 直接买最便宜轻量服务器（约 ¥30-60/月），照 C 的 Docker 步骤部署即可 |
