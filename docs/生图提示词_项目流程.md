# 悦己美妆智能客服 Agent —— 生图模型提示词包

> 用途：为项目生成架构图 / 对话流程 / 数据流水线 / README 封面等配图
> 适用模型：即梦、通义万相、可灵、DALL·E 3、GPT-4o、Midjourney 等
> 关键提醒：**多数生图模型对中文文字的渲染不可靠**。若需文字标签，优先用支持文字渲染的模型（GPT-4o / 通义万相 / 即梦），或让模型生成"无文字版"后用 PPT/设计工具叠加标注（见 §7 变体）。

---

## 0. 使用说明

1. 每段提示词 = **【共享风格基础】+【场景正文】**，复制时把两段拼接为一整段提交；
2. 比例建议：架构图/流程图用 **16:9**；封面 Banner 用 **16:9 或 3:2**；
3. 生成后若某元素错位，可追加描述微调（如"把'意图路由'节点移到中间"）；
4. 若模型不支持中文提示词，直接用英文版（§8）。

## 7. 无文字版变体（推荐：先出图后叠字）

在任意提示词末尾追加：

```
中文版：画面中不包含任何文字、字母或数字，只保留图形与图标，标题区域留白
英文版：no text, no letters, no numbers anywhere in the image, graphics and icons only,
blank space reserved where labels should go
```

生成后用 Figma / PPT / 可画叠加中文标注，文字绝对清晰。

---

## 8. 各模型使用建议

| 模型 | 建议 | 说明 |
|------|------|------|
| GPT-4o / DALL·E 3 | 文字渲染最稳，适合含标签版本 | 直接用英文版提示词，标签写英文更可靠 |
| 即梦 / 通义万相 / 可灵 | 中文提示词直接可用 | 对中文短标签支持较好，仍建议少字 |
| Midjourney | 画面质感最强 | 建议无文字版 + 后期叠字；加 `--ar 16:9 --style raw` |
