# 部署手册

## 1. 架构

```
Streamlit 前端 (8501)  <--HTTP-->  FastAPI (8000)  <---> DeepSeek API / Ollama(bge-m3)
                                      |
                                   SQLite (data/db/yueji.db)
```

- **LLM**：DeepSeek `deepseek-chat`（主），Ollama qwen2.5（兜底）
- **Embedding**：Ollama bge-m3（本地，1024 维）
- **检索**：Dense + BM25 + RRF 融合（可配 LLM 重排）

## 2. 本地部署（开发）

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # 填入 DEEPSEEK_API_KEY

# 数据准备（一次性）
python -m scripts.gen_data      # 40款产品/217条FAQ/10条政策
python -m scripts.gen_orders    # 20条模拟订单
python -m scripts.ingest        # 知识库向量化（需 Ollama bge-m3）

# 启动
python -m uvicorn src.api.main:app --host 0.0.0.0 --port 8000   # 后端
streamlit run frontend/app.py                                    # 前端

# 自检
python -m scripts.check_env
```

## 3. Docker 部署

```bash
docker compose up -d --build
# 访问 http://localhost:8501
# API 文档 http://localhost:8000/docs
```

> 注意：Docker 容器内需要能访问 Ollama（embedding）。若 Ollama 在宿主机，
> 设置 `OLLAMA_BASE_URL=http://host.docker.internal:11434`（Linux 需 `extra_hosts` 或在 compose 中配置）。

## 4. 评测与测试

```bash
python -m pytest tests/ -q                        # 单元测试
python -m eval.evaluate                           # 全量评测（100条）
python -m eval.evaluate --quick 20                # 快速评测
python -m scripts.stress_test --concurrency 50    # 并发压测
# 报告输出到 eval/reports/
```

## 5. 环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| DEEPSEEK_API_KEY | - | 必填，DeepSeek 开放平台 |
| OLLAMA_BASE_URL | http://127.0.0.1:11434 | Ollama 服务地址 |
| EMBED_MODEL | bge-m3 | 嵌入模型 |
| RETRIEVE_MIN_SCORE | 0.02 | RRF 融合阈值（低于视为无可信答案） |
| RERANK_ENABLED | false | 是否启用 LLM 重排 |
| RATE_LIMIT_PER_MIN | 20 | 每会话限流 |

## 6. 常见问题

- **DeepSeek 401**：检查 `.env` 中 API Key。
- **嵌入失败**：确认 Ollama 已启动且 `bge-m3` 已拉取（`ollama pull bge-m3`）。
- **进程退出挂起**：脚本请通过 `close_db()/close_llm()` 清理（或直接 `asyncio.run` 单次）。
- **Python 3.14 依赖问题**：见 `docs/开发笔记.md` 的版本预案。
