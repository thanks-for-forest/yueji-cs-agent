## 项目一句话简介

基于 **RAG（Dense+BM25+RRF）+ Function Calling + 多 Agent 路由 + 情绪转人工** 的美妆电商智能客服系统，覆盖商品咨询、订单查询、退换货、护肤推荐四大场景，Python/FastAPI/Streamlit 全栈实现，最终评测 100 条测试集问题解决率 100%、幻觉率 0%。

## 版本更新（2026-08-25，5 个新 commit）

1. **feat: 用户绑定**（12ca911）：会话归属校验 + 订单按用户隔离
   - API：`POST /api/session` 绑定 user_id；chat/history 归属校验不一致返回 403；`GET /api/sessions?user_id=` 过滤
   - 工具层：注册表通过 `_ctx` 注入 user_id（**不进 LLM 工具契约**）；订单/物流/售后 `_fetch_order` 校验 `order.user_id`，他人订单视为未找到（**不泄露存在性**）
   - 前端：侧边栏用户 ID 输入，聊天请求带身份；兼容未绑定会话（user_id="" 保持原尾号校验行为）；41 项测试全过
2. **feat: 〔来源〕可点击跳转知识库原文**（e8af074）：`GET /api/source/{label}` 来源详情页（深色科技风 HTML）+ `/raw` 原始 JSON；`parse_sources` 提取干净 source_id（P011/F020/POL-1）
3. **fix: 纯产品名来源 404**（5aa85db）：`_resolve_sources` 支持 带编号标签/纯编号/纯名称 三种形态（按产品名/FAQ问题/政策类型名匹配）
4. **fix: 前端推荐卡片 NameError**（01e3718）：`_render_order_card/_render_recommendations` 移到历史渲染循环之前（模块级代码自上而下执行的坑）
5. **fix: 创建会话 422**（2586d76）：`create_session` body 可缺省
